# Personal Expense Tracker
A console-based expense management application built using Java.
## Features
- Add and view expenses
- Calculate total expenses
- Edit and delete expenses
- Record expense dates
- Save and load expenses using file handling
- Handle invalid menu choices and expense numbers
## Technologies Used
- Java
- ArrayList
- Object-Oriented Programming
- File Handling
## How to Run
1. Install the Java Development Kit (JDK).
2. Open the project in VS Code.
3. Run `Main.java`.
4. Follow the menu displayed in the console.
## Project Purpose
This project was developed to practise Java programming, object-oriented concepts, collections, and file handling.
